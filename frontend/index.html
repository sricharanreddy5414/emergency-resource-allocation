SUPPORT CENTER

Help & FAQ

Learn how the ERAP platform works.

How does resource allocation work?

A request is sent through API Gateway to Lambda. Lambda checks DynamoDB for a matching available resource and processes the configured priority rules.

What happens after allocation?

The allocation is recorded and a ResourceAllocated event can be published through EventBridge and delivered through SNS notifications.

What does Priority 1 mean?

Priority 1 represents the highest configured request priority in this demonstration platform.

Is ERAP a real emergency system?

No. ERAP is a cloud-computing demonstration project using fictional/test data. It is not intended for real emergency or medical decision-making.
