SUPPORT CENTER

How to operate ERAP

The paths that exist in this product.

Getting started

Sign in, select the organization, then select a location. Resources, requests, and allocations on the following screens belong to that organization.

Resource operations

Register a resource with a resource type, location, availability, and public or private visibility. Available resources can be matched. Allocated resources can be released.

Request and allocation workflow

Create a request with a request type, location, and priority. Priority 1 is the highest. Allocation matches that request to an available resource. Release returns the resource to available.

Resource Exchange Network

Exchange lets verified organizations request and offer resources across organizations. Creating an offer does not hold a resource. Accepting an offer holds it. Ownership and location change only after the requester confirms handover. Quantity-resource handover is not supported yet.

Billing

ERAP is in a Controlled limited beta. Organizations are onboarded deliberately. Owners and admins can open Billing for the selected organization. The page shows the subscription state and the catalog prices returned by ERAP. A new organization starts a 15-day trial. The owner can start checkout only for a plan ERAP marks as available. Checkout opens the provider page and does not by itself mark the subscription active. The deployed provider integration remains the Razorpay test integration until a separate production secret is configured. A verified provider event is what changes the subscription state. Cancellation, when the owner requests it, is scheduled through the end of the current period, and operational access continues until then. Refunds have no automatic engine. A refund request is a manual support process, and the provider record stays authoritative. Organization records stay in place. Company approval recorded for the current V1 launch documents. That company approval is not legal counsel approval.

Team access

Owners and admins invite people by verified email. Roles are OWNER, ADMIN, OPERATOR, and MEMBER. An invitation grants no access until it is accepted. Removing a member deactivates that membership.
